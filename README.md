This depository contains files pertaining to sample & practical certification exams from DataCamp. More specifically, they directly pertain to exams done in Python, R, &/or SQL.

Most certifications were completed between late 2024 & late 2025; however, some required renewals after two years following completion. For example, the Python Data Associate & SQL Associate certifications were firstly completed in November, 2024, but renewals were completed in August, 2026.  
The Data Analyst Associate certification was achieved in March, 2025. The Data Analyst certification was achieved in November, 2025.
